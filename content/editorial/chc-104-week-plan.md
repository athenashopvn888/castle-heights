# Castle Heights Cannabis: 104-Week / 312-Post Editorial Architecture

Status: **HOLD — manager review, same-day fact check, independent copy review, and owner approval required before any publication.**

This is a three-post-per-week architecture: 104 weeks × 3 distinct posts = **312 held concepts**. Nothing in this file creates a route, enters a sitemap, or authorizes publication. Week 1 begins only when the owner approves a start date.

## Exact week mapping

The 13-week cadence below runs eight times. An absolute week is calculated as `(cycle number - 1) × 13 + cadence week`.

|---:|---:|---|
| 1 | 1-13 | First-visit essentials |
| 2 | 14-26 | Product-format choices |

| 5 | 53-65 | Adult shopper comparisons |
| 6 | 66-78 | Late-night and flexible visit planning |

Every cycle must produce a new title, slug, introduction, and buyer question. A cycle angle never justifies a near-duplicate post. Each slot must pass a query-ownership, cannibalization, and meaningful-uniqueness gate; if it does not, the concept must be replaced rather than lightly renamed. Cycle 8 remains public shopper content; technical SEO, canonical, sitemap, image-alt, audit, and workflow topics belong in a separate private maintenance log.

## Measurement plan

Measurement belongs to MasterAdmin / the SEO reviewer. Tony owns drafting and assignments but does not receive GSC baseline, result, or tracking fields.

For every published post, record the publication date and run these checkpoints against the canonical `https://www.castleheightscannabis.ca/` GSC property:

| Checkpoint | Review |
|---:|---|
| 7 days | Confirm indexing/canonical selection, inspect early impressions and query relevance, and verify required internal links in both directions |
| 28 days | Record clicks, impressions, CTR, average position, indexed status, leading queries, and whether another CHC URL is competing for the same query |
| 90 days | Compare clicks, impressions, CTR, average position, indexing, query ownership, and internal-link contribution with the 7- and 28-day snapshots; decide keep, improve, consolidate, or retire |

The review must note seasonality, the site's short data history, and low-volume uncertainty. No checkpoint creates a ranking guarantee, and an early position change is not proof of causation. Do not rewrite a protected winner or publish another competing page solely because a new article has limited early traffic.
